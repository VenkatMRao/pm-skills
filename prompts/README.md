# Prompts

Tool-agnostic prompt templates — copy-paste into Claude.ai, ChatGPT, or any
chat-based LLM. Unlike the skills in [`../skills/`](../skills/), these don't need
Claude Code; they're single prompts for lower-stakes or one-off tasks.

Each file has the prompt itself plus a short note on when to use it and what input
it expects.

| Prompt | Use it for |
|---|---|
| [`user-research-synthesis.md`](user-research-synthesis.md) | Turning raw interview notes/transcripts into themes, verbatims, and recommendations |
| [`stakeholder-update.md`](stakeholder-update.md) | Turning bullet-point status notes into a polished stakeholder update |
| [`feature-spec-review.md`](feature-spec-review.md) | Critiquing a draft PRD/spec for gaps before it goes to review |
